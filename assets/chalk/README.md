# Chalk illustrations — scroll-drawn

Black chalk line drawings that draw themselves as the guest scrolls, then stay drawn.
No libraries; one small script plus one SVG per illustration.

## What's in here

```
chalk-draw.js      the drawing/scroll script (load once per site)
demo.html          scroll test page with every illustration
svg/               one SVG per illustration (clean line paths + stroke weights)
```

The SVGs are the *source* lines. The chalk texture, pressure variation and scroll
animation are generated by `chalk-draw.js` in the browser, so to edit a drawing you
only edit the paths. The `data-*` attributes on each `<svg>` hold its pressure
profile — leave those as they are.

## 1. Put it in the repo

Copy this folder into the wedding-site repo as `illustrations/`, so the files serve from:

```
https://tttibs.github.io/wedding-site/illustrations/chalk-draw.js
https://tttibs.github.io/wedding-site/illustrations/svg/monogram.svg
```

GitHub Pages sends the CORS header the script needs to fetch the SVGs from the Webflow domain.

## 2. Load the script in Webflow (once)

Site settings → Custom code → **Before `</body>` tag**, below your existing script tag:

```html
<script src="https://tttibs.github.io/wedding-site/illustrations/chalk-draw.js" defer></script>
```

It's guarded against Webflow loading footer code twice.

- `aspect-ratio` reserves the space before the SVG loads, so nothing jumps.
- **Size:** the monogram and church fill their container — size them by setting the
  width of the Embed's parent (or add a class with a width in Webflow).
- **Food objects** are sized from their native size × `--chalk-scale` (default `0.7`).
  That keeps line weight identical across all the objects even though they're
  different sizes. To make the whole set bigger or smaller, set it once site-wide,
  e.g. in Site settings → Head code: `<style>:root{--chalk-scale:0.9}</style>`.
  You can also set it on a single section to resize just the items inside it.

## Options (attributes on the div)

| Attribute | Default | What it does |
|---|---|---|
| `data-chalk-color` | `#111` | Ink colour, any CSS colour |
| `data-chalk-start` | `0.9` | Starts drawing when its top reaches this point of the screen (0 top → 1 bottom) |
| `data-chalk-end` | `0.45` | Fully drawn when its middle reaches this point |
| `data-chalk-mode` | (scroll) | `manual` ignores scroll; the drawing waits for `ChalkDraw.play(el, ms)` and then draws over `ms` milliseconds. For fixed-position drawings (intro, frame) and ones that move sideways |

Behaviour:
- Drawing follows scroll position but never goes backwards; once drawn it stays.
- Anything already scrolled past (e.g. reload halfway down) finishes drawing quickly.
- Items near the very bottom of the page finish when the guest hits the bottom.
- Only illustrations near the screen are built, so lots of them is fine on mobile.
- Reduced-motion users see the finished drawing straight away.
- When one finishes, its div gets the class `chalk-drawn` and fires a `chalk:drawn` event,
  handy if you want text to fade in after it.
- `ChalkDraw.complete()` in the console finishes everything instantly (useful when designing).

## Testing locally

`demo.html` fetches the SVGs, so open it through a local server rather than double-clicking:

```
python3 -m http.server   # then visit http://localhost:8000/demo.html
```
